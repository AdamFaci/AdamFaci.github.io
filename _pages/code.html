SegmentART

Python Apache-2.0

Assisted image annotation combining manual prompts — box, positive and negative points — with automatic segmentation by SAM 2, followed by semantic grouping and structured, Visual Genome-style description. It is designed to cut both the time and the number of interactions a dense annotation requires, and it records fine-grained interaction telemetry so that annotation strategies can be compared against one another.

The point is not only speed. In the humanities the hard part is that one object admits several levels of interpretation, so the tool aims at richer descriptions — attributes, relations, hierarchies — rather than flat labels. Annotation runs in two phases: first load images, draw boxes, add positive and negative points, run SAM 2 and validate the masks; then group validated objects by similarity and generate multi-level semantic descriptions. Masks are stored as lossless compact RLE, two to three orders of magnitude smaller than dense arrays, and exports target Visual Genome, COCO and a custom format.

The codebase is split in two layers: a backend/ holding the logic with no interface dependency, and a Streamlit frontend/. That separation is deliberate — it lets the same logic drive other annotation platforms such as Label Studio or CVAT. Python 3.11+; SAM 2 is an optional dependency installed separately.
