"How does this author's use of the term change across the corpus?" and "What does this passage say?" are not the same information need, yet a standard RAG pipeline treats them identically. This work types the question by the function it requires and routes it to a corresponding neuro-symbolic plan, whose steps remain individually inspectable and re-runnable.
